How to read this view

Commit — a saved snapshot of the project. Each row is one commit, newest at the top.
Coloured lines — lines of development. Each line connects a commit to the one it was built on (its parent). Two lines side by side means work happened in parallel.
Merge commit (hollow dot) — joins two lines of work back together, e.g. a feature branch merged into main.
main
Branch — a movable name pointing at a commit. The filled one is the branch you're on (HEAD).
origin/main
Remote branch — where a branch was on the server (e.g. GitHub) the last time you fetched. A cloud on a local branch means it matches its remote copy.
v1.0
Tag — a permanent label, usually marking a release.
↑2↓1
Ahead / behind — your branch has 2 commits not yet pushed, and the remote has 1 commit you haven't pulled.
Uncommitted changes — edits in your folder that aren't saved into a commit yet.
