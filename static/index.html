How to read the commit & branch graph

Commit — a saved snapshot of the project. Click any commit in the list to see what changed.
Coloured lanes & animated flow — lines of development. Hover any branch in the sidebar or select a commit to watch animated pulses trace that branch's history.
Merge commit (hollow dot) — joins two lines of work back together, e.g. a feature branch merged into main.
main
Branch — a movable pointer to a commit, colour-coded to match its lane. The filled badge is the branch you're on (HEAD).
origin/main
Remote branch — where a branch was on the server (e.g. GitHub) at your last fetch. A cloud on a local branch means it's in sync with its remote copy.
v1.0
Tag — a permanent label, usually marking a release version.
↑2↓1
Ahead / behind — your branch has 2 commits not yet pushed, and the remote has 1 commit you haven't pulled.
Uncommitted changes — edits in your working folder that aren't saved into a commit yet.
